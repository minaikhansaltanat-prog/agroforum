Спикер фотолары осы қалтаға салынады / Speaker photos go here.

1. Файлды осында қойыңыз (WebP немесе JPG, шаршы 600x600 px, бет ортада): sp1.webp
2. site/js/config.js ішіндегі speakerPhotos объектісіне жолды қосыңыз:
     speakerPhotos: { sp1: "img/speakers/sp1.webp" }
Кілттер: sp1..sp5 (ҚазҰАЗУ ғалымдары), ss1 (арнайы баяндамашы), gs1, gs2 (құрметті қонақтар).
Фото жоқ болса, бас әріптері көрсетіледі.
