# Агрофорум 2026: сайт

Халықаралық форумның «Қазақстанның ауыл шаруашылығын дамытудың өзекті мәселелері: ғылым мен тәжірибе диалогы» бір беттік сайты. Күні: 3 желтоқсан 2026, Алматы, ҚазҰАЗУ. Тілдері: қазақша (негізгі), орысша, қытайша, өзбекше, қырғызша.

Техникалық тапсырма: [TZ.md](TZ.md). Өнім мен дизайн контексті: [PRODUCT.md](PRODUCT.md), [DESIGN.md](DESIGN.md). Мәтін стратегиясы: [docs/COPY-STRATEGY.md](docs/COPY-STRATEGY.md).

## Не бар

Сайт `site/` қалтасында: таза HTML, CSS, JS. Сыртқы кітапхана да, Google қызметтері де жоқ, сондықтан Қытайдан ашылады. Қаріптер (Montserrat, Inter) сайтпен бірге жүктеледі.

```
site/                 жарияланатын сайт (Vercel осыны береді)
  index.html          бет (қазақша мәтін алдын ала жазылған)
  css/style.css       жиналған стиль (src/css/ ішінен жасалады)
  js/config.js        ТҮЗЕТІЛЕТІН БАПТАУЛАР: WhatsApp, Kaspi, Google Sheets, орын саны, фото
  js/app.js           тіл, мәзір, анимация, бейне, форма
  l/kk.js ru.js zh.js uz.js ky.js   барлық мәтін (data-i кілттері)
  img/ fonts/ videos/ docs/         суреттер, қаріптер, бейнелер, бағдарлама PDF
src/css/              стильдің бастапқы файлдары
scripts/              build, тексеру, скриншот құралдары
docs/                 мәтін стратегиясы, Google Apps Script
assets/ videos/ Photo/ current/ TZ.md    тапсырыс беруші берген бастапқы материалдар
```

## Жергілікті іске қосу

```bash
npm install            # бір рет (puppeteer-core, axe-core)
npm run serve          # http://localhost:3000
npm run build          # CSS жинау + қазақша мәтінді HTML-ге жазу (мәтін немесе стиль өзгерген сайын)
npm run check          # 5 тілдік файлдың кілттері, «тегін», 400, 09:00, ұзын сызық, араласқан әріп
npm run e2e            # мәзір, тіл, форма, бейне тесті (сервер қосулы болуы керек)
npm run axe            # қолжетімділік тексеруі (5 тіл, телефон мен компьютер)
npm run shot           # скриншот: node screenshot.mjs http://localhost:3000 [атау] --w 390 --sections
```

## Нені қайда өзгертеміз

- **Мәтін.** `site/l/kk.js` (және ru, zh, uz, ky). Жаңа кілт бес тілге де қосылады, `npm run check` қатені көрсетеді. Сосын `npm run build`.
- **Баға мен пакет құрамы.** `pk1_list`, `pk2_list`, `pc1_list`, `pc2_list` тізімдері тілдік файлдарда; баға `site/index.html` ішінде (5 000 / 30 000 / 100 000 / 150 000).
- **«20 орынның N қалды».** `site/js/config.js`: `partnerLeft`.
- **Спикер фотосы.** Файлды `site/img/speakers/` қалтасына салып, `config.js` ішіндегі `speakerPhotos` өрісіне жолын қосыңыз (кілттер: sp1..sp5, ss1, gs1, gs2). Фото болмаса, бас әріптері көрінеді.
- **Бейнедегі спикерлердің аты-жөні.** `config.js`: `videoPeople` (қазір «жақында қосылады» көрсетіледі). Мәтінді `l/*.js` ішінде өзгертуге де болады (`v_pending`).
- **Серіктес логотиптері.** `config.js`: `partnerLogos`.
- **Бейне.** `site/videos/`: promo-kk.mp4, promo-ru.mp4 (басқа тілдерде орысша көрсетіледі), organizer-1..3.mp4 («Ұйымдастырушылар үндеуі»). Бейнелер `preload="none"`, бір мезетте біреуі ойнайды.
- **Бейнені жаңарту.** Бастапқы файлдар `V/` папкасында (өте үлкен, сондықтан GitHub-қа салынбайды). Сайтқа арналған нұсқа: `ffmpeg -i "V/файл.mp4" -vf "scale=720:1280:flags=lanczos,format=yuv420p" -c:v libx264 -preset slow -crf 28 -maxrate 1000k -bufsize 2000k -g 60 -c:a aac -b:a 96k -map_metadata -1 -movflags +faststart site/videos/organizer-N.mp4`. Постер: `ffmpeg -ss 14 -i "V/файл.mp4" -frames:v 1 -vf scale=540:960 -c:v libwebp -quality 80 site/img/poster-organizer-N-540.webp` (кадрлар 14, 1 және 92 секундтан алынған).
- **Фото.** Бастапқы файлдар `assets/photos` және `Photo/`; сайтқа WebP нұсқасы `site/img/` ішінде.

## Тіркеу формасы, Google Sheets және төлем

1. Форма деректері Google Sheets-ке түседі: [docs/google-apps-script.gs](docs/google-apps-script.gs) файлындағы нұсқаулықты орындап, шыққан сілтемені `config.js` → `sheetsUrl` өрісіне қойыңыз. Сілтеме қойылмайынша форма жұмыс істейді, бірақ деректер сақталмайды (консольде ескерту шығады).
2. Kaspi төлем сілтемелері: `config.js` → `pay` (4 пакет). Форма жіберілген соң таңдалған пакеттің сілтемесі «Kaspi арқылы төлеу» батырмасымен ашылады. Сілтеме жоқ болса, «WhatsApp-қа жазу» батырмасы дайын хабарламамен көрсетіледі.
3. Телефон нөмірі бетте жазылмайды: WhatsApp нөмірі `config.js` → `whatsapp` ішінде, тек сілтеме ішінде қолданылады.

## Жариялау (Vercel)

Репозиторийдің түбірінде `vercel.json` бар (`outputDirectory: site`), сондықтан Vercel жобасын осы репозиторийге байлауға болады (Framework: Other, build командасы бос). Немесе Root Directory ретінде `site` көрсетіңіз. Консольден: `cd site && vercel --prod` (жоба `agroforum-2026`).

Домен қосылған соң `agroforum-2026.vercel.app` мекенжайын `site/index.html` (canonical, og:url, og:image, hreflang, JSON-LD), `site/robots.txt`, `site/sitemap.xml`, `site/js/config.js` (`site`) ішінде жаңа доменге ауыстырыңыз. Vercel Analytics өзі қосылады (Project > Analytics). Оқиғалар: тіркелу батырмалары, пакет таңдау, WhatsApp, форма, бейне, тіл ауыстыру.

## Клиенттен әлі күтілетіндер (TZ.md, 10-бөлім)

1. Домен атауы (Vercel-ге қосу құқығымен).
2. Kaspi төлем сілтемелері не QR (4 пакет).
3. Бірінші бейнедегі ұйымдастырушының (Расул) толық аты-жөні мен лауазымы. 2 және 3-бейненің соңғы карточкасында «ҚАТЫСУ ТЕГІН», 09:00 және телефон нөмірі жазылған, ол сайттағы ақылы пакеттер мен 09:30-ға қайшы: карточканы кесу не жаңа нұсқа керек.
4. Спикерлердің фотолары, серіктестердің логотиптері.
5. Кешкі ас өтетін мейрамхананың атауы мен мекенжайы.
6. Қайтару шарттары: қазір FAQ-та «жақында нақтыланады» деген уақытша мәтін тұр (`a3`, барлық тілде).
7. 2ГИС және Яндекс карта сілтемелерін нақты нүктеге ауыстыру (қазір университет атауы бойынша іздеу сілтемесі).
8. Шақырылған, бірақ растала қоймаған қонақтардың (арнайы баяндамашылар, құрметті қонақтар) аты-жөнін жариялауға келісімін растау. Шетелдік қонақтардың аты-жөні қасақана көрсетілмеген.

## Дизайн қысқаша

Ашық, ауа көп, редакциялық стиль: фон `#FBF8F1`, карточкалар `#FFFFFF`, жолақтар `#F3EEE2`, мәтін `#0B1F3A`, алтын `#C9A24A`, жасыл `#2E7D4F`. Қою көк тек футерде. Идея: форум атауының өзі (диалог) сайттың құрылымына айналған: фермердің сұрағы мен ғалымның жауабы («Не аласыз» бөлімі, FAQ, сұрақ өрісі). Анимация тек `transform` және `opacity`, `prefers-reduced-motion` қолданылады. Телефонда: үш сызықты мәзір (X батырмасымен жабылады), оның ішінде бөлімдер, астында тіл ауыстырғыш.
